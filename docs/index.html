Fonctionnalités Principales

Ce que l'écosystème After The Whistle permet de réaliser grâce à l'association des données et du LLM.

🏀

Widgets Dynamiques

Des interfaces visuelles (Box scores interactifs, Courbes de Momentum, Timelines) renvoyées directement dans le chat via le protocole MCP.

📊

Données Déterministes

Le moteur packages/core calcule les séquences (runs) et identifie les moments clés de manière mathématique avant d'informer le LLM.

🗣️

Personas Multiples

Analysez un match avec le ton analytique d'un coach, l'emphase d'un supporter ou le style cash d'une discussion de comptoir.

🔗

Sécurité du Contexte

Zéro hallucination. Le LLM ne devine pas les statistiques ; il se contente d'interpréter le JSON précis généré par le serveur MCP.
