Ce que fait vraiment l'app

Une surface de discussion, pas un RAG générique

Le backend charge ou ingeste le match, calcule les anomalies et les séquences, puis expose un widget React à ChatGPT avec des faits vérifiés.

1

Box Score Cliquable

Le widget affiche les lignes joueurs/équipes et appelle `get_stat_context` sur les stats utiles.

2

Insights Déterministes

Runs, droughts, momentum et stints sont calculés dans `packages/core`, avec evidence refs.

3

Analyse Visuelle

`show_analysis` rend un panneau focus joueur, équipe, turning point, recap ou débat.
