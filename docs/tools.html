Outils MCP Disponibles

Les fonctions exposées à ChatGPT via chatgpt-app.json pour construire les UI interactives.

Outil (Tool Name) Description & Usage LLM Paramètres (JSON Schema)
show_game Outil principal pour afficher le Box Score complet d'un match. Déclenche le Canvas par défaut. 
{
  "gameId": "string"
}
get_stat_context Appelé automatiquement quand l'utilisateur clique sur une statistique. Renvoie les play-by-plays justifiant le chiffre. 
{
  "gameId": "string",
  "playerId": "string",
  "statCategory": "enum",
  "runId": "string (opt)"
}
get_momentum Génère les données vectorielles (SVG data) pour tracer la courbe de domination d'une équipe. 
{
  "gameId": "string"
}
show_analysis Affiche une vue spécialisée (Focus joueur, Focus équipe) isolée du Box Score classique. 
{
  "gameId": "string",
  "viewMode": "string",
  "template": "string"
}
clear_cache Vide la base de données SQLite locale pour forcer un rafraîchissement depuis les API sportives.
