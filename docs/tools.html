Les 8 tools exposés à ChatGPT

Cette page reprend les schémas réels de `packages/mcp-server/src/tool-schemas.ts`. Les anciens champs `playerId`, `statCategory` ou `template` ne sont plus le contrat actuel.

show_game

Tool principal. Charge un match, retourne le widget, les box lines, prompts, insight bundle, team stats et scoring runs.

UI resourcerefresh/cache
{
  "gameId": "basket:0022400500",
  "query": "Spurs",
  "sport": "basket",
  "refresh": true,
  "clearCache": true,
  "tone": "analyst"
}

show_analysis

Rend une analyse visuelle. Le payload `analysis` est obligatoire et doit rester ancré dans les faits vérifiés.

standalonemodel-authored
{
  "gameId": "basket:0042400407",
  "viewMode": "standalone_analysis",
  "analysisTemplate": "player_focus",
  "analysis": {
    "title": "SGA control game",
    "thesis": "...",
    "points": [{ "label": "Creation", "detail": "..." }]
  }
}

get_stat_context

Appelé par le widget sur clic de stat. Retourne contexte texte, blocs, plays, faits liés, stints éventuels et headline UI.

widget clickverified context
{
  "gameId": "basket:0042400407",
  "entityId": "player_sga",
  "entityName": "Shai Gilgeous-Alexander",
  "teamId": "team_okc",
  "statKey": "ast",
  "tone": "analyst"
}

list_suggested_prompts

Produit les questions suggérées depuis les insights, avec priorité aux gros runs et moments tardifs.

{ "gameId": "basket:0042400407", "tone": "debate" }

get_shot_chart

Retourne les tirs d'un joueur NBA et le profil d'efficacité quand les données sont disponibles.

{ "gameId": "basket:0042400407", "entityId": "player_sga" }

get_momentum

Retourne la courbe de momentum, depuis SQLite si disponible ou recalculée depuis la timeline.

{ "gameId": "basket:0042400407" }

get_player_stints

Retourne les segments on-floor/on-pitch et le différentiel depuis la perspective du joueur.

{
  "gameId": "basket:0042400407",
  "entityId": "player_sga",
  "entityName": "Shai Gilgeous-Alexander",
  "teamId": "team_okc"
}

clear_cache

Supprime un match du cache SQLite, ou tout le cache si `gameId` est omis.

{ "gameId": "basket:0042400407" }

Le contrat affiché ici doit évoluer avec `tool-schemas.ts` et `schema-contract.ts`.
