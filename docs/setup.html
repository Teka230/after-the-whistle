Démarrage Rapide

Installez After The Whistle localement ou via Tailscale pour une exposition distante.

Développement Local
Configuration Tailscale
Variables d'Environnement

1. Cloner et Installer

git clone https://github.com/Teka230/after-the-whistle.git
cd after-the-whistle
pnpm install

2. Démarrer le serveur MCP

Le serveur tourne par défaut sur le port 8788 pour éviter les conflits.

pnpm run build
pnpm --filter @after-the-whistle/mcp-server start

Exposition sécurisée avec Tailscale Funnel

Si vous utilisez ChatGPT sur le web (hors application desktop), vous devez exposer le serveur MCP en HTTPS.

# Exposer le port 8788 sur le réseau public
tailscale funnel 8788

# Récupérer l'URL générée (ex: https://machin.tailscale.net)
# Mettre à jour chatgpt-app.json avec cette URL

Fichier .env à la racine

Ces variables sont nécessaires pour que le core accède aux statistiques brutes.

MCP_PORT=8788
SPORTS_API_KEY=your_api_key_here
ENABLE_SQLITE_CACHE=true
