Monorepo pnpm

Le LLM explique. Le backend calcule.

L'app n'est pas un RAG classique. Elle produit d'abord des faits vérifiés, puis ChatGPT les transforme en discussion, visualisation ou débat selon le ton demandé.

Pipeline

Du fournisseur au commentaire

1
Discovery

`query` ou `gameId` est normalisé, puis résolu dans le cache ou via scoreboard/fixtures.

2
Ingestion

Les données sont chargées depuis NBA Stats ou ESPN, puis stockées dans le cache SQLite.

3
Insight Engine

`core` calcule faits, runs, momentum et prompts. Le LLM ne les invente pas.

4
Widget MCP

ChatGPT affiche la ressource HTML et le widget rappelle les tools accessibles si l'utilisateur clique.

Architecture alignée avec les packages TypeScript du dépôt.
