Le Problème

Le Concept Déterministe

Sans After The Whistle

Demandez à un LLM d'analyser un match de basket récent. Soit il ne l'a pas dans ses données, soit il l'a lu sur internet. S'il l'a lu, il va résumer le ton général d'un article. S'il manque de données, il va halluciner des statistiques (ex: inventer qu'un joueur a marqué 30 points).

Avec After The Whistle

Le modèle utilise le Model Context Protocol (MCP) pour interroger la base de données locale du projet. Le package @after-the-whistle/core calcule les Momentum Runs et les performances avant d'envoyer un JSON strict et formel au LLM. Le LLM ne fait qu'habiller la donnée exacte avec le ton demandé.

Architecture

Monorepo Turborepo

Le projet est divisé en packages modulaires pour séparer la logique d'analyse de l'affichage UI.

@after-the-whistle/core

Le moteur d'insights. Contient la logique d'identification des runs, les formules de possession et l'orchestration déterministe.

@after-the-whistle/mcp-server

L'interface avec ChatGPT (Port 8788). Déclare les outils via chatgpt-app.json et parse les requêtes du LLM pour appeler le core.

@after-the-whistle/widgets

Les composants UI React (Canvas). Stylisés via styles.css, ces widgets sont injectés dans ChatGPT par le serveur MCP.

Base de données locale

Stockage SQLite local pour mettre en cache les PBP (Play-By-Play) et éviter d'atteindre les limites de taux de l'API sportive.

Providers Externes

Connecteurs vers NBA Stats, API-Football ou autres fournisseurs de données sportives brutes.
